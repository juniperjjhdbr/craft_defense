**Craft Defense** is a mod that aims to bring tower defense gameplay to Minecraft. Inspired by games like All Star Tower Defense (Roblox) and Bloons TD 6, the mod features a raid system with two towers, one of which will spawn enemies and the other the player will need to defend with mini units they can obtain during their journey.

Upon completing a raid, all players will earn rewards, the main one being the **"Tower Gem,"** which is the mod's main item. With it, players can obtain better units. In addition to the Tower Gem, one of the unit mechanics is the level system, which can make a unit deal more damage depending on its level.

## **BLOCKS AND ITEMS:**

#### **Tower Gem:** As described before, the Tower Gem is the mod's main item. With it, players can roll better units and craft the Epic Upgrade.

![](https://media.forgecdn.net/attachments/description/1362605/description_eeb682f3-fc9e-48c5-962b-e7966ee0c4d2.gif)

**Trait Cube (NEW):** This item is used to roll traits for your units inside a Trait Reroller! Traits can give a unit buffs and debuffs.

![](https://media.forgecdn.net/attachments/description/1362605/description_c4549f8b-b08d-4c0c-ab3c-04af260cc0ec.gif)

#### **Raid Manager:** This is the mod's main block; it's how players can start and enter raids.

#### ![](https://media.forgecdn.net/attachments/description/1362605/description_c0b0be5a-cb28-433c-b43b-a3c6de5beb3f.png)

**Unit Machine:** This block is used to roll better units; each roll uses two Tower Gems.

#### ![](https://media.forgecdn.net/attachments/description/1362605/description_35e862e0-9eca-4de4-bc16-eaea7b71f10c.png)

**Trait Reroller (NEW):** This block is used to roll traits; each roll uses one Trait Cube.

![](https://media.forgecdn.net/attachments/description/1362605/description_01e3c6d7-12f1-402c-a671-e57a6690f760.png)

**Epic Upgrade:** This item is used to roll epic units inside a Unit Machine.  
**Trophies:** These are obtained when the player completes Act 5 of their respective worlds.
